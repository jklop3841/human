# Human 1.0.0 — Agent-Readable Corpus

Release date: 2026-09-11  
Author: Lu Cheng / 卢成 / Jack Lu

## Release meaning

Human 1.0 does **not** mean the author's theory of humanity is complete.

It means the archive now has a stable machine-access layer:

`discover -> bootstrap -> retrieve -> canonical source -> provenance/evidence -> relations -> regenerate -> distribute -> query via MCP`

### Epistemic metadata

Standardized provenance classes:

`P0 human_raw`
`P1 human_structured_author_confirmed`
`P2 formal_repo_author_confirmed`
`P3 reconstructed_memory`
`P4 agent_summary_or_extension`
`P5 external_evidence_or_counterexample`

Standardized evidence levels:

`E0 hypothesis`
`E1 anecdotal/single case`
`E2 limited empirical`
`E3 multi-study/replicated`
`E4 systematic/meta/strong convergence`
`NA not applicable`

### Deterministic corpus regeneration

- `tools/build_agent_corpus.py`
- `tools/requirements-agent-export.txt`

The builder can flatten institution YAML into institution JSONL, extract formal viewpoint metadata, build a file manifest, calculate SHA-256 checksums and mirror generated data into the Hugging Face staging directory.

### agentarchitect.me discovery layer

The controlled website repository was identified as:

`jklop3841/agentarchitect-site`

The following discovery routes were added to its `main` branch:

- `/human`
- `/human/manifest.json`
- `/human/corpus.jsonl`
- `/human/claims.jsonl`
- `/human/relations.jsonl`
- `/human/institution-index.jsonl`
- `/llms.txt`
- `/llms-full.txt`
- `/.well-known/agent.json`
- `/agents.txt`

The website acts as the identity/discovery layer while the Human GitHub repository remains canonical. The `/human/*.jsonl` routes redirect to canonical raw GitHub objects instead of duplicating mutable corpus data.

Production deployment was **not verified** in this release because the connected Vercel context exposed no visible team/project.
