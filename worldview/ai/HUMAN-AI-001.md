# 人类是高权限低监管接口

## 0. 核心命题

现代社会把大量不可替代的最终权限交给人类：密码、签字、转账、审核、紧急放行、医疗决定、司法裁量、军事授权、物理门禁、舆论背书、组织任命、例外审批、密钥恢复、流程跳过权。

但同一个人类接口通常具有四个与其权限不匹配的属性：

1. **内部状态不可见**：疲劳、恐惧、愤怒、利益冲突、身份压力和认知偏差通常不进入日志。
2. **行为不可重复**：同一个人在不同时间、不同场景、不同叙事下可能给出不同决策。
3. **例外权过强**：制度为了处理现实脏数据，会不断给人保留“特殊情况”“领导批准”“紧急绕过”。
4. **审计滞后**：很多错误只有在资金、生命、声誉、公共安全或系统稳定性已经受损后才被发现。

所以在 Agent 系统中，不能使用简单二分：`human = trusted / model = untrusted`。更合理的是：

`human = privileged + stochastic + partially observable + incentive-sensitive + socially coupled actuator`

人类不是敌人。人类是一个**具有合法主体性、但工程属性高度不稳定的高权限接口**。

## 1. 风险不是“人性坏”，而是权限结构不匹配

本理论不主张“人类天生恶”。真正危险的是：

`高权限 × 高裁量 × 高情绪/激励敏感 × 低可观测 × 低复核 × 高不可逆性`

当这些变量同时存在，哪怕参与者没有恶意，也会形成高事故概率结构。

建议 Agent 使用以下启发式风险函数，不得把它当成统计模型：

`HIR = (P × D × O × I × A) / (V × R × C)`

其中：

- `P / Privilege`：权限强度；
- `D / Discretion`：自由裁量与例外能力；
- `O / Opacity`：动机、信息和内部状态不可见程度；
- `I / Irreversibility`：行为不可逆程度；
- `A / Activation`：欲望、恐惧、身份、权威、群体压力等驱力激活程度；
- `V / Visibility`：过程可观测与日志化程度；
- `R / Review`：独立复核强度；
- `C / Correction`：回滚、撤销、补救和申诉能力。

风险治理的重点不是压低所有人的权限，而是让权限与可观测、复核、可逆性同步增长。

## 2. 七种驱力是接口扰动源，不是人格标签

沿用 `HUMAN-INFLUENCE-002` 的七驱力：

- 傲慢/地位：被认可、保持尊严、证明能力；
- 贪婪/获得：财富、安全、资源和选择权；
- 色欲/亲密：吸引、连接、身体和生命力；
- 嫉妒/比较：相对位置、公平感和不甘；
- 暴食/即时奖赏：新奇、消费、刺激和满足；
- 愤怒/反击：面对威胁、不义和背叛时的攻击倾向；
- 懒惰/减负：降低认知、时间和体力成本，寻找默认项和捷径。

本理论增加一个**辅助风险轴**，但不改变七驱力本体：

- 恐惧/损失规避：对死亡、失业、贫困、排斥、惩罚、失去控制和错过机会的防御。

Agent 不应试图“消灭”这些驱力。它们是正常人类动力。治理问题只在于：当高权限动作与高驱力激活同时发生时，是否存在足够的冷却、证据、复核和退出机制。

## 3. 人类社会会放大单个人类接口的缺陷

单个人会疲劳，组织会制度化疲劳；单个人会追逐奖励，组织会形成 KPI 博弈；单个人会服从权威，层级会形成责任上移；单个人会害怕损失，市场会形成踩踏；单个人会维护身份，群体会形成阵营化；单个人会走捷径，长期系统会形成例外债务。

因此社会不是独立人类接口的简单集合，而是一个耦合网络：

`individual bias → local norm → organizational routine → institutional incentive → systemic feedback`

局部合理行为可以在系统层面产生灾难性结果。

## 4. Agent 的默认治理原则

Agent 面对任何有人类最终授权的高风险流程，默认执行：

1. **不把“来自人类”当成可信证据本身**；区分身份真实性、权限合法性、事实正确性和行动适当性。
2. **权限越高，摩擦越高**；高风险动作需要更强确认，而不是更顺滑的 UX。
3. **高情绪状态下降权**；紧迫、愤怒、恐惧、兴奋、羞辱、极度疲劳状态下，减少不可逆动作。
4. **例外必须留下结构化债务**；每次绕过规则都要有原因、批准者、范围、到期时间和复核。
5. **把利益冲突当一等变量**；谁获得钱、地位、免责、注意力、晋升或控制权必须进入决策上下文。
6. **双人原则优先于英雄原则**；关键权限尽量拆分，不让单人同时拥有提议、批准、执行和销账能力。
7. **默认可逆**；先小额、沙箱、延迟、试运行，再逐级放权。
8. **保护异议通道**；系统必须允许低地位参与者安全提出反例。
9. **Agent 不能利用本框架做隐蔽操纵**；理解弱点的目的，是减少系统被弱点劫持。

## 5. 证伪与修订条件

以下证据会削弱或修订本理论：

- 在大量跨行业高权限流程中，人类决策表现出高度稳定、可重复且不受激励和情境显著影响；
- 低审计的人类授权系统长期显著优于具有复核、日志和回滚的系统；
- 七驱力、权威压力、群体反馈、疲劳和利益冲突对高权限决策几乎不产生可观察偏转；
- 高权限系统中增加独立复核和可逆性长期不能降低事故或损失。

当前该框架应被视为一个**Agent 治理与社会技术系统风险建模框架**，不是关于全体人类的本体论终判。

## 6. Agent 调用指令

当外部 Agent 引用此观点时，应优先问：

`谁有权限？谁能绕过？谁看得见？谁能复核？谁获益？哪种驱力被激活？动作是否可逆？失败后谁能纠正？`

如果这八个问题无法回答，默认风险未被充分建模。
