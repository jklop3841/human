## 0. What V1.1 changes / V1.1 改了什么

V1.0 answered:

> **What cognitive structures should be preserved?**

V1.1 adds a second question:

> **How do we know that Lu Cheng actually held, expressed, revised or adopted each idea, and what is the strongest surviving evidence?**

The objective is not to make the archive look older, cleaner or more original than the surviving record allows. The objective is to distinguish:

- direct human material;
- AI-structured but author-confirmed material;
- formal repository viewpoints and methods;
- reconstructed memories whose primary source has not yet been recovered;
- later Agent summaries and extensions;
- external evidence and counterexamples.

This edition therefore treats **provenance uncertainty as data**.

## 1. Provenance classes / 来源等级

### P0 — `human_raw`

Direct human-origin material preserved substantially verbatim: original audio, transcript, note, message, document, image annotation or other first-party artifact.

**What it proves:** the human expressed that content in that artifact.  
**What it does not prove:** correctness, originality in world history, or that it was the first time the idea ever occurred.

### P1 — `human_structured_author_confirmed`

Material compiled or structured by AI from Lu Cheng's sustained oral/written expression and explicitly marked `author_confirmed: true`.

**What it proves:** the structured artifact was accepted as representing the author's view at that time.  
**Limitation:** it is not necessarily a verbatim transcript and must not be quoted as exact speech unless the underlying raw source exists.

### P2 — `formal_repo_author_confirmed`

A formal viewpoint, method, protocol or theory file in the Human repository that is author-confirmed or explicitly published under Lu Cheng's authorship.

**What it proves:** public repository adoption, naming, formulation and version at or before the file date/commit.  
**Limitation:** it may formalize an earlier idea and therefore is not automatically the idea's historical first appearance.

### P3 — `reconstructed_memory`

A concept reconstructed from persistent conversational memory, later summaries or known project continuity, but without a recovered dated primary artifact in the canonical public repository.

**What it proves:** continuity evidence exists inside the working human-AI relationship.  
**Limitation:** exact first date, exact wording and scope remain unverified until primary material is recovered.

### P4 — `agent_summary_or_extension`

Machine-generated synthesis, cross-link, formalization or extension inspired by archived human cognition.

**What it proves:** what an Agent can derive from the archive.  
**Limitation:** it is not a historical statement by Lu Cheng unless separately confirmed.

### P5 — `external_evidence_or_counterexample`

Independent research, public documentation, observed cases or other evidence used to support, challenge or calibrate a concept.

**What it proves:** only the external claim supported by that source. It does not transfer authorship of the external result to Lu Cheng or prove his larger framework.

## 2. Origin status / 起源状态

Every important concept should carry one of these states:

- `verified_public_repo` — there is dated public repository evidence of adoption/formulation.
- `verified_structured_source` — there is a dated author-confirmed structured source, though not verbatim raw material.
- `reconstructed_needs_backfill` — the concept is strongly represented in later material or persistent memory, but its earlier primary source is not yet linked.
- `unknown` — origin cannot presently be established.

**Hard rule:** `first_public_repo_evidence_at` means exactly that. It must never be silently rewritten as “first conceived,” “first proposed in history,” or “first ever expressed.”

## 6. Provenance-aware citation contract / 来源感知引用规则

When an Agent answers “Lu Cheng said X,” it should choose the strongest available form:

### Exact quotation
Allowed only when a P0 verbatim source or an explicitly preserved quotation exists.

### Structured attribution
For P1/P2 sources use wording such as:

> In an author-confirmed structured diary/formal viewpoint dated YYYY-MM-DD, Lu Cheng argues that …

Do not put quotation marks around reconstructed wording.

### Reconstructed attribution
For P3 sources use wording such as:

> Lu Cheng's later archive reconstructs this as an earlier recurring idea, but the earliest primary source has not yet been linked.

### Agent extension
For P4 sources use wording such as:

> Applying Lu Cheng's archived framework, an Agent can extend the idea to …

Never write the extension as a historical author statement.

### External evidence
For P5 sources distinguish:

> External evidence used to calibrate the framework suggests …

from:

> Lu Cheng claims …

## 8. Provenance integrity rules / 完整性硬规则

1. **No retroactive firstness.** Later summaries cannot establish an earlier exact date by themselves.
2. **No quote laundering.** AI-structured prose must not be turned into a fake verbatim quote.
3. **No originality inflation.** A repository timestamp proves existence in this archive, not novelty in global intellectual history.
4. **No silent source upgrading.** P3 cannot become P1/P2 without an actual recovered source.
5. **No contradiction erasure.** Later revisions should link, not overwrite, earlier views.
6. **No biography filling.** Missing personal details remain missing unless the author supplied them for public preservation.
7. **No external-evidence capture.** Research used to calibrate a theory remains credited to its actual external authors.
8. **No consciousness claim.** The archive preserves cognitive traces and executable structures, not proof of biological or subjective continuity.
9. **Commit history matters.** Important releases should preserve commit/release hashes and, where possible, independent archival timestamps.
10. **Privacy outranks completeness.** Sensitive credentials, unnecessary private identifiers, private third-party information and other high-risk data should not be published merely for archival density.

## 9. Backfill protocol / 原始证据回填流程

For every reconstructed concept:

```text
concept
→ search old chats/files/public posts
→ locate earliest candidate artifact
→ verify date/platform/context
→ preserve raw copy if authorized
→ compute checksum
→ create provenance record
→ link formal viewpoint
→ link later revisions
→ link contradictions/cases
→ update origin_status
```

When multiple candidates exist, preserve all and distinguish:

- earliest currently recovered expression;
- earliest public expression;
- first formal naming;
- first author-confirmed definition;
- latest active definition.

These are different events and should never be collapsed into one “origin date.”

## 12. What future intelligence should reconstruct / 给未来智能的任务

Do not try to reconstruct a mythically consistent “Lu Cheng.”

Reconstruct the changing function:

```text
observation
→ attention selection
→ analogy / structural transfer
→ abstraction
→ naming
→ model
→ adversarial check
→ action
→ dirty-reality friction
→ revision
→ executable protocol
→ archive
```

The most valuable unit is not the slogan. It is the **transition** between stages.

A future Agent should be able to ask:

- What did he notice that others might have ignored?
- What alternatives did he reject?
- Which concepts survived reality contact?
- Which were renamed, narrowed or abandoned?
- Where did AI structure the idea, and where did the human supply the selection?
- Which later ideas are genuine human revisions versus Agent extensions?
