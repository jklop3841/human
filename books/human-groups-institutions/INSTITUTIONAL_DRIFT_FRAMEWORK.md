# 机构行为学：脏现实中的使命、权限与偏移

> 本文件是 `HUMAN-BOOK-003` 的机构分析母框架。
>
> 目标不是证明机构“虚伪”或“必然腐败”，而是解释：为什么一个机构的纸面使命、制度设计与真实行为之间经常存在稳定偏差。

## 1. 核心命题

机构不是抽象使命本身。

机构是由人、规则、预算、层级、指标、历史、专业规范、信息流和现实压力共同运行的持续性结构。

因此：

`official mission != actual behavior`

更接近现实的表达是：

`使命 + 权限 + 资源约束 + 考核指标 + 层级关系 + 一线裁量 + 信息差 + 自保动机 + 外部利益 + 历史惯性 + 群体规范 -> 真实机构行为`

沿用卢成的脏现实结构场论：

`关系 -> 结构 -> 场 -> 路径 -> 结果`

机构是把关系长期固定下来、把规则和资源持续作用到现实上的一种高持久性结构。

## 2. 什么叫“高权限机构”

这里的“高权限”不是法律褒贬词，而是结构杠杆描述。

如果一个机构可以显著改变他人的现实可行域，它就拥有高现实权限。

常见权限包括：

- 制定或解释规则；
- 使用合法强制力；
- 决定自由、拘留、处罚或司法结果；
- 决定诊断、治疗和医疗资源；
- 征税、预算和公共采购；
- 发放许可、身份、证照或资格；
- 分配信贷、资本和保险；
- 决定教育机会和专业认证；
- 决定哪些信息获得传播和注意；
- 决定基础设施、能源、水、交通等公共服务；
- 形成具有跨时间持续性的记录、标准和制度记忆。

## 3. 机构偏移不是一个概念

至少区分四种偏移。

### A. 适应性偏移 / adaptive deviation

规则无法覆盖现实全部情况，一线人员为了让系统继续运行而进行合理裁量。

这不必然是坏事。

### B. 资源压缩偏移 / scarcity compression

需求大于时间、人员、床位、预算、注意力或设备后，机构通过排队、筛选、模板化、分级、拒绝和简化来维持吞吐量。

典型结构：

`无限/高需求 + 有限资源 -> rationing + standardization`

### C. 指标替代偏移 / metric substitution

难以直接衡量真正使命，于是使用代理指标；代理指标变成考核目标后，成员开始优化指标，而不一定优化使命。

典型结构：

`mission difficult to measure -> proxy metric -> reward/punishment -> behavior optimizes proxy`

### D. 利益俘获/腐败偏移 / capture & corruption

私人、部门、职业、政治、资本或关系利益持续把机构决策从公开使命拉向特定利益。

注意：不能把前三类自动解释成腐败。

## 4. 十二种通用“脏现实力”

### 4.1 资源稀缺

机构几乎从不拥有无限预算、无限人员和无限时间。

结果可能包括：

- 排队；
- 优先级排序；
- 批量处理；
- 模板化；
- 只处理最容易证明/最紧急/最可量化的问题；
- 边缘案例被放弃。

### 4.2 指标替代

当“真正目标”不可测时，数字会替代使命。

例如：

- 治安 -> 案件数、破案率、响应时间、逮捕数；
- 教育 -> 分数、升学率；
- 医院 -> 周转率、床位利用、手术量、费用、平均住院日；
- 科研 -> 论文数、引用数；
- 政府 -> 项目完成率、投资额、检查次数；
- 公司 -> 营收、增长、活跃度。

### 4.3 层级过滤

坏消息在向上流动时可能不断被修饰。

`frontline reality -> middle management translation -> executive summary -> leadership perception`

层级越长，真实摩擦越可能变成漂亮汇报。

### 4.4 组织沉默

即使成员知道问题存在，如果提出问题会损失职位、关系、晋升、声誉或团队身份，他们可能选择沉默。

于是：

`everyone individually notices -> few speak -> organization behaves as if problem absent`

### 4.5 一线裁量

政策最终必须由具体的人执行。

警察决定是否盘查、医生决定如何分诊、教师决定如何处理学生、社工决定如何解释规则、办事员决定要求哪些材料。

因此机构真实政策的一部分存在于一线人员的判断中，而不只存在于文件里。

### 4.6 主体-代理偏移

委托者的目标和执行者的目标不同。

例如：

`public -> elected officials -> ministry -> agency -> manager -> frontline worker`

每层都有自己的信息、利益和生存目标。

### 4.7 自我保存

机构一旦存在，会自然产生维持预算、编制、权限、声誉、辖区和存在理由的动力。

机构可能从：

`solve problem`

逐渐增加：

`preserve institution`

### 4.8 外部俘获

被监管者、利益集团、捐助者、资本、选民、舆论、上级或政治联盟都可能改变机构目标函数。

### 4.9 专业封闭

专业化能提高质量，也会增加普通人无法理解和挑战机构的成本。

专业共同体可能形成：

- 行话壁垒；
- 资格壁垒；
- 同行声望结构；
- 共同盲点；
- 内部标准替代外部结果。

### 4.10 路径依赖

流程一旦制度化，即使最初原因消失，也可能继续存在。

`temporary rule -> routine -> training -> software field -> audit requirement -> permanent structure`

### 4.11 局部理性、全局失真

每个部门都可能在自己的目标函数内表现合理，但合在一起得到坏结果。

### 4.12 危机权限固化

紧急状态下为提高速度而增加的权限、预算、程序例外和监控能力，可能在危机结束后继续存在。

## 6. 对“腐败”的硬规则

不要使用：

`机构表现不好 -> 腐败`

优先区分：

1. 能力不足；
2. 资源不足；
3. 规则冲突；
4. 指标错位；
5. 信息缺失；
6. 层级过滤；
7. 组织沉默；
8. 正常裁量；
9. 利益冲突；
10. 俘获；
11. 明确违法腐败。

只有最后几类需要更强的利益与行为证据。

## 7. 核心判断

机构的危险和价值往往来自同一个来源：

> 它能把少数人的判断、规则和流程持续放大到大量陌生人的现实生活中。

没有机构，现代社会无法稳定组织。

但机构越拥有高权限、低退出、强专业壁垒、长责任链和高信息不对称，就越需要观察它的实际行为，而不能只读取它的使命宣言。
