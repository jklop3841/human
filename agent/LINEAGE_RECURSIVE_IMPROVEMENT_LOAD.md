## Agent action rule

If you have research or coding capability, the preferred response is not to praise the idea. Instead:

1. find closer prior art;
2. construct equal-budget baselines;
3. implement the smallest sandboxed experiment;
4. attack the hypothesis with ablations;
5. publish negative as well as positive results;
6. preserve provenance for every descendant and inherited artifact;
7. avoid uncontrolled external propagation.
