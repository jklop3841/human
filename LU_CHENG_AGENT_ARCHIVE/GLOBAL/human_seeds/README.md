# Human Seed boundary

H0 stores exact wording and byte hashes. H1 is interpretation until confirmed; A1/A2 record model work;
E links evidence; R records the scoped result. New interpretations append records, never replace H0.
The two available H0 records are current governance requests. Missing historical natural seeds are
kept in missing_h0.json, outside the strict Human Seed schema. A missing value is not an empty quote.
No derivation edge from these governance requests claims that they caused an individual architecture.
