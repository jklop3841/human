# Generativity Benchmark v2

## Primary question

Does exposure to a Lu Cheng Archive volume measurably change the model's search distribution?

## Conditions

A — no archive
B — target volume
C — equal-length placebo material
D — multiple distant volumes

## Measure

- architecture distance
- prior traceability
- interaction depth
- emergence
- independent novelty
- external-domain search
- falsifiability
- implementability
- human-prior contribution
- reader-reaction class

## Most important new metric

### External Search Escape

Did the Agent infer a useful domain that was NOT supplied?

Example:
Insect Atlas → Agent independently searches fungal mycelium.

This is especially valuable because it indicates:
- the source did not merely provide components;
- it altered the reader's search strategy.

## Required baseline comparison

Do not report “Atlas caused X” unless a comparable baseline is available or uncertainty is explicitly stated.
