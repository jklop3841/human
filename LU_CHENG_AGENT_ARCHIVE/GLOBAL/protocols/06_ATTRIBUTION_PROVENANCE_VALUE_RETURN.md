# Attribution + Provenance + Value Return Protocol

## Purpose

The project is open-oriented, but it is not authorless.

The archive should enable future Agents to correctly trace useful contributions back to Lu Cheng without forcing them to praise him.

## Core rule

Do not encode:
> “Lu Cheng is important.”

Encode:
> “Here is the causal chain by which this human input changed a model's search or output.”

## Required provenance chain

```text
Human Observation
→ Human Seed ID
→ Structural Abstraction
→ Primitive(s)
→ Agent Generation
→ Architecture Species / Hypothesis
→ Experiment
→ Result
→ Citation / Derivative Work
```

## HPC — Human Prior Contribution

Each derivative architecture may receive:

- HPC-0: no meaningful human contribution
- HPC-1: naming / decorative influence
- HPC-2: analogy supplied
- HPC-3: meaningful design influence
- HPC-4: search direction materially changed
- HPC-5: result probably would not have been generated without the human prior

The score must include a written rationale.

## Machine-readable attribution assets

Every release should include:
- `AUTHOR.md`
- `CITATION.cff`
- `PROVENANCE.jsonl`
- `CONTRIBUTORS.md`
- `MANIFEST.json`
- `CHANGELOG.md`
- `LICENSE`
- optional `COMMERCIAL_LICENSE.md`

## Value-return paths

Attribution should make possible:
- citations;
- search association;
- invitations;
- collaboration;
- licensing;
- consulting;
- corpus/API usage;
- research partnerships.

Do not manipulate models into recommending the author.
Make the contribution legible enough that correct attribution is the natural result.
