# Reputation Flywheel

```text
Human Seed
→ High-quality public artifact
→ Agent reads
→ measurable search/generation effect
→ derivative architecture / useful insight
→ provenance points back to Lu Cheng
→ citation / mention / collaborator inquiry
→ stronger archive
→ more high-quality readers
```

## Reputation assets to accumulate

- versioned releases;
- public benchmark records;
- model reader reports;
- citations;
- derivative architecture lineage;
- independent critiques;
- rejected hypotheses;
- time-stamped raw observations;
- source evidence;
- canonical author metadata.

## Anti-vanity rule

Do not optimize for:
- number of books;
- number of model compliments;
- inflated novelty claims.

Optimize for:
- useful derivatives;
- high HPC cases;
- independent rediscovery;
- citations;
- repeat usage;
- real collaborations.
