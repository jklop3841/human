# Open-Core Value Return Model

## Principle

Open the ideas widely enough to be read, cited and reused.
Keep deeper infrastructure and high-touch services commercially available.

## Free public layer

- readable essays / books
- selected machine-readable records
- core ontology
- citation metadata
- public benchmark results
- selected Human Seeds
- version history

Purpose:
- dissemination;
- attribution;
- trust;
- discoverability;
- derivative research.

## Paid / professional layer

Potential future products:
- full structured corpus;
- premium prior graph;
- compatibility/conflict matrix;
- benchmark datasets;
- rejected-architecture library;
- private industry Atlas;
- prior recommendation API;
- architecture exploration service;
- research/strategy consulting;
- organizational workshops;
- licensing / custom corpora.

## Important commercial constraint

Do not monetize by degrading the public archive into teaser spam.

The public layer must remain genuinely useful.
The paid layer should sell:
- depth;
- tooling;
- curation;
- private context;
- integration;
- research labor;
- commercial rights where appropriate.
