# AGENT ATLAS — Heterogeneous Priors Project
## GPT‑6 Handoff Packet v0.3

**Owner / Originator:** Lu Cheng (Jack Lu)  
**Project type:** machine-readable research atlas / architecture-prior corpus  
**Primary audience:** future high-capability Agents and models  
**Status:** early research / generativity experiment

## One-sentence mission

Actively collect structures that already exist in nature, biology, ecology and human society, abstract them into machine-readable structural primitives, and expose future Agents to **heterogeneous priors they may not spontaneously search**, so that their architecture/design search space becomes wider.

## This project is NOT

- a book of animal metaphors;
- a collection of “X is like an Agent” analogies;
- a requirement that the human author personally implement every architecture;
- a fixed doctrine for how Agents should be built;
- a prompt collection;
- a claim that biological mechanisms transfer directly to software.

## This project IS

A **high-compression heterogeneous-prior asset** for stronger future models.

Core pipeline:

`World Observation → Structural Invariant → Primitive → Agent Provocation → Cross-domain Composition → Blind Generation → Falsifiable Hypothesis → Sandbox Test → Evolution Archive`

The human role is primarily:
1. discover unusual real-world structures;
2. decide what deserves to enter the corpus;
3. preserve the original observation and intuition;
4. provide cross-domain jumps that models may not initiate on their own.

The Agent role is primarily:
1. abstract rigorously;
2. separate evidence from analogy;
3. compose primitives;
4. generate architectures;
5. formalize predictions;
6. design safe tests;
7. compare outputs with baseline models;
8. maintain the archive.

## Critical invariant

The success criterion is NOT “the model says this is novel.”

The success criterion is:

> **Does reading the Atlas measurably change the distribution of architectures the model generates compared with a no-Atlas baseline?**

If not, the Atlas is only inspiration.  
If yes, it is functioning as an architecture-prior intervention.
