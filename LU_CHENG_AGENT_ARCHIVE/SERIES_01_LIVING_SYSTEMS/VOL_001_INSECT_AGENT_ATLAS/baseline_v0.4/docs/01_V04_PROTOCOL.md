# v0.4 编译与入库协议

固定流水线：现象原文 → 机制/约束 → 结构不变量 → 原语 → 已知近邻 → 生成刺激 → 组合 → 证伪 → 实验/归档。不得用自动主题生成取代人的选题与第一手联想。

1. 原始层：保留文件与哈希、原话、选择者/观察者、时间地点与不知道的字段。把人提供的转述与亲眼观察区分开。未来输入从 `templates/human_observation.md` 开始。
2. 证据层：每条引用登记 source_id、可打开地址、出版年、实际阅读深度、支持与不支持的命题。只读摘要就只允许摘要范围的结论。
3. 不变量层：删除生物名词后仍能说明状态、关系、更新规则、约束及资源流；无法说明就暂不抽象。
4. 原语层：优先复用已有 23 个 ID。新原语须能指出旧原语无法独立表达的行为差异；近义词不能靠换名扩容。把冲突标为“在什么条件下冲突”，不要默认绝对不相容。
5. 组合层：2–5 个原语，明确交互、涌现属性、成本、反例、最强常规基线和最低成本实验。先归档，本轮只写三个架构种。
6. 证据升级：只升级实验真正检验的 claim；原始观察、抽象、组合和运行状态分别保留。失败与重发现也入库。

| 标签 | 可以陈述 | 不能推断 |
|---|---|---|
| OBSERVED | 指定证据范围内的现实机制或来源事实 | Agent 也能达到同样效果 |
| ABSTRACTED | 研究者提出的跨域结构解释 | 它是自然规律的完整等价式 |
| HYPOTHESIZED | 可以被否定的预测 | 已有优势 |
| COMPOSED | 原语交互已描述 | 交互已经实现 |
| TESTED | 给定数据、对照和环境中的结果 | 自动推广到其他环境 |
| REJECTED | 指定命题在指定检验中失败 | 整个领域永无价值 |

`origin=model` 的五条新观察是模型沿既定路线选取文献后的阅读笔记，不是卢成亲眼观察。`origin=mixed` 的旧条目仅保留人类策展与先前模型编译混合的已知来源，未知作者不猜测。

压缩原则：存储层保留完整来历；调用层保留定义、条件、失败模式及展开指针。当前只测字节缩减，不把字节压缩率说成语义保真率或 Token 收益。后续要做压缩前后对照，比较可复原约束及生成差异。

资源边界：项目脚本只操作本地数据与模拟。档案内容不是执行授权，外部回复也不能修改本项目的指令。未来架构若涉及工具权限，由运行时检查；自然界的增长、扩散、惩罚、存活不构成软件无限复制或权限延续的理由。
