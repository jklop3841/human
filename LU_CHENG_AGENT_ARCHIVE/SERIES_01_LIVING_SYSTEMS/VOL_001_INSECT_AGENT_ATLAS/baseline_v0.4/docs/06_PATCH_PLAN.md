# 下一补丁执行表

本轮 v0.4 是可执行研究基线。后续依次完成以下补丁；不得先扩展更多架构种。

| 顺序 | 补丁 | 输入接口 | 执行动作 | 验收 / 停止条件 |
|---|---|---|---|---|
| P0 | 原始材料补回 | 原始 v0.2 压缩包、原始模型回复及各自提示 | 归档、哈希、逐条比对、保留当前迁移谱系 | 没拿到就保持缺失；不拼造作者、版本、全文 |
| P1 | 三条件首次实跑 | 一个实际可用模型；三个独立会话或可隔离 API | 登记身份与设置，按 FIRST_THREE_CALLS.md 提交，导入完整回复 | 三次原文与元信息完整；污染会话剔除，不把结果挑着留下 |
| P2 | 完成多模型 pilot | 另外两个可记录身份的模型与剩余调用 | 固定任务/材料跑完54次；两个独立评审 | 完整性、组别泄漏和无效输出先过关，再解释效应 |
| P3 | 证据范围加深 | 五篇论文的完整方法与免疫论文勘误 | 补充约束/反例，必要时撤销原语或收窄边界 | 只读摘要的条目不升级成完整机制核验 |
| P4 | 编译压缩检验 | 完整原语 vs 当前压缩原语 | 固定任务测试约束可还原性与生成差异 | 过度压缩丢关键条件就回退 |
| P5 | 机制与常规原语对照 | pilot 中确有影响的原语 | 加同格式的常规工程原语 D 组；一次只去掉一个关键机制 | 无额外机制增益则记为一般结构化提示效果，不继续扩架构数量 |

冻结窗口：在首个完整 pilot 出结果前不新增世界领域、不换主任务、不优化已看到结果的提示。修正事实错误必须升材料版本并重新开 run，不覆盖旧运行。

人只需提供原始材料与真实模型返回；代码校验、匿名导出、结果聚合由执行 Agent 完成。接口不足只影响外部实跑，不妨碍已授权的本地建设和验证。

对外可发现性先交付 `dist/INDEX.json`、`dist/agent_priors.jsonl` 和版本包。它们可被其他 Agent 明确导入；本轮没有公开发布、没有上传训练平台、没有声称未来模型会自动发现。发布地址和受众另由项目所有者决定。
