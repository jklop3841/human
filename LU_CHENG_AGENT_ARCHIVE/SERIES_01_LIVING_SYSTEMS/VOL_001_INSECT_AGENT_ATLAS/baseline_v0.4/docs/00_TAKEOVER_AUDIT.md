# v0.4 接管审计

接管依据：原封保留的 `05_GPT6_MASTER_PROMPT.md`。项目名称、核心目的、人的选择权与验收条件沿用 v0.3。本轮执行者为 ChatGPT Work Mode assistant，精确后端模型标识未提供；文件名不是模型身份凭据。

已读取 15 个文件的全部文本，含 Word 主文、表格、脚注和评论 XML；Word 没有图片媒体。输入逐文件哈希和读取范围见 `archive/intake_manifest.json`。原文件均保存在 `archive/v0.3/`。

| 原有资产 | 交接包实际包含 | v0.4 处理 |
|---|---|---|
| 12 个昆虫模式 | 表格摘要与 Word 总结 | ID、表格原文和映射保留；原生模式正文仍缺失 |
| 18 个原语 | 名称、类别及简要描述 | 保留名字/含义；新增定义、图边与失效条件标为本轮注释 |
| 8 个种子组合 | 名称、父模式和一句说明 | 明示 reconstructed 原语分配；缺失证伪/实验字段保持未知 |
| 多模型阅读发现 | 至少一个模型生成新结构的转述 | 记为非受控历史线索，不进入基准结果 |

历史转述不足以识别模型版本、提示词、完整输入、采样设置、选择过程或独立性。无法从该包恢复原始六模型回复或 MDS Mesh 完整 JSON；不依据会话外摘要拼造它们。

缺失层与补丁：

| 缺口 | 为什么影响验收 | 本轮落点 |
|---|---|---|
| 逐项证据与阅读深度 | 不能区分摘要支持、原文支持、模型补全 | sources.jsonl + provenance + claims |
| 记录状态与认知层混用 | ARCHIVED 是归档动作，不能当成科学证据 | 保留旧 status；新增 archive_status 与逐条 epistemic_status |
| 原语依赖/冲突语义 | 列表无法说明组合是否成立 | parents、interaction_candidates、conflicts、环境条件；校验引用与父图无环 |
| 常规工程近邻 | 容易把缓存、蚁群、局部控制换名当新发明 | 文献注册 + 保守 novelty_class |
| 压缩的可展开性 | 只有标签会丢失约束和失效条件 | dist 紧凑记录保留行为/边界，并指回原始记录 |
| 条件污染、伪独立与等长对照 | 同一上下文评审不能构成干预实验 | 冻结提示、独立会话元信息、匿名评分、按调用聚合 |
| 真实运行和模拟混淆 | 本地脚本测试不等于 Atlas 有效 | 零真实模型调用；模拟结果单独标注作用范围 |

生物映射重点待校准：蟑螂聚集不是分布式系统强一致性证明；蝴蝶变态不直接推出权限递减；蚜虫形态可塑性不等于个体“自主设计下一代”；甲虫生态位多样不直接证明稳定软件内核；蜉蝣短寿命不自动证明短命 Agent 更省钱。这些映射保留为可检验解释，不删除历史原意，也不升级成自然事实。

项目仍处于研究验证期。当前验收问题保持为：暴露于该资产是否改变架构生成分布。它与自然知识是否新鲜、架构能否盈利、模型是否自称受到启发分别记录。
