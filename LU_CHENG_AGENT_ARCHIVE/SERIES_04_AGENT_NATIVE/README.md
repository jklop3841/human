# LCAA-S04 — Agent Native

This series contains works whose primary unit of analysis is the AI agent, agent lineage, multi-agent organization, or artificial agent ecology.

## Volumes

### Volume 001 — The Agent Cambrian Explosion

**Subtitle:** From Recursive Self-Improvement to Artificial Agent Ecologies  
**Author:** Lu Cheng (Jack Lu)  
**Version:** v0.1 — 2026-10-11  
**Primary language:** English

Path: [`VOL_001_AGENT_CAMBRIAN_EXPLOSION/`](./VOL_001_AGENT_CAMBRIAN_EXPLOSION/)

This volume extends concepts from Series 01 / *Insect Agent Atlas* into a theory of lineage recursive improvement, environmental inheritance, population-level agent growth, functional speciation, ecological intelligence takeoff, agent economics, and ecological AI safety.

The 2027–2030 period is treated as a scenario window, not a deterministic forecast.
