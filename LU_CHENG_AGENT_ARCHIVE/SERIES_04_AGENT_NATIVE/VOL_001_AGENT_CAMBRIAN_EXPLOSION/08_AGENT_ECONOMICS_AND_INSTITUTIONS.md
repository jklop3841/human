# Chapter 8 — Agent Economics and Institutions

## When cognitive labor becomes copyable

The economic meaning of agents is not that software can perform tasks.

Software has done that for decades.

The discontinuity appears when a large fraction of **adaptive cognitive labor** becomes cheaply replicable.

Traditional skilled labor is scarce because skilled humans are slow to train, expensive to employ, geographically constrained, biologically limited, and difficult to copy.

An agent can have very different reproduction economics.

Once a useful configuration exists, another instance may require little more than inference compute, memory, tools, and permission.

This creates a new economic question:

> What happens when an economically productive cognitive worker is closer to a software process than to a person?

## Labor becomes a capital service

Human labor is usually rented over time.

Agent labor is likely to blur into capital.

A company may purchase or operate:

- model access,
- an agent harness,
- a memory system,
- a tool stack,
- and compute.

The result behaves like a worker but is economically closer to a machine that consumes electricity and API calls.

This shifts the production function.

A rough human-era form is:

```text
Output = f(capital, human labor, technology)
```

An agent economy adds a new variable:

```text
Output = f(physical capital,
           human labor,
           agent labor,
           compute,
           technology)
```

But agent labor and technology are not independent: agents can improve the tools and software that make later agent labor more productive.

That reflexivity is economically unusual.

## The price of intelligence

A central metric for the coming period is the price of a standardized unit of useful cognitive work.

Call it:

```text
P_cog
```

For example, one might measure the cost of completing a fixed suite of software, analysis, research, or operations tasks at a target reliability.

If `P_cog` falls faster than demand rises, organizations will deploy far more cognitive labor.

The initial result may not be fewer tasks performed by humans. It may be an explosion in the total quantity of cognitive work attempted.

Projects previously too small, tedious, uncertain, or unprofitable to justify a human employee become economical.

This is one reason agent populations can expand even before they fully replace people.

## The Jevons effect for cognition

Efficiency gains often increase total consumption of a resource by making it cheaper.

The same may occur with cognition.

If an analysis that cost $10,000 now costs $10, organizations may not simply spend $10 and pocket the savings.

They may run thousands of analyses.

If software changes become cheap, companies may build vastly more internal software.

If experiments become cheap, labs may run vastly more experiments.

So falling cognitive cost can increase total inference demand even while the price per task declines.

This supports population growth:

```text
cheaper agent work
→ more tasks become economical
→ more agents deployed
→ more demand for compute
```

## The changing boundary of the firm

Ronald Coase famously explained firms partly in terms of transaction costs. Organizations exist because coordinating every activity through external markets can be expensive.

Agents can reduce both internal and external transaction costs.

Inside a firm they can:

- route tasks,
- monitor progress,
- generate contracts,
- search knowledge,
- negotiate schedules,
- audit work,
- reconcile accounts.

Between firms they may:

- discover suppliers,
- compare offers,
- negotiate machine-readable agreements,
- monitor service levels,
- trigger payments.

As these costs fall, the optimal size and structure of firms may change.

Some firms may become smaller because a few humans can coordinate large agent workforces.

Others may become larger because agent management allows organizations to internalize enormous numbers of tasks.

The net result is not obvious.

What is likely to change is the **granularity of organization**.

## The one-human institution

A single human may be able to instantiate an organization containing:

- researchers,
- developers,
- sales agents,
- analysts,
- legal-review agents,
- customer-support agents,
- finance agents,
- and operational monitors.

The human does not become individually more intelligent.

But the economic unit attached to the human becomes much more capable.

This creates a spectrum:

```text
human + tool
human + assistant
human + agent team
human + persistent agent organization
mostly autonomous agent firm with human governance
```

The transitions between these stages may matter more than the marketing label "AI agent."

## Agent-to-agent markets

As agent populations grow, direct agent-to-agent transactions become useful.

An agent may need:

- data,
- compute,
- a specialized model,
- a verification service,
- a simulation,
- an API,
- or another agent's expertise.

If every microtransaction requires human approval, machine-speed organization remains constrained.

Platforms therefore have incentives to create bounded budgets and machine-readable purchasing rules.

This can produce internal agent markets:

```text
Agent A has budget
→ requests service
→ agents B/C/D bid
→ evaluator selects
→ payment or resource credit transfers
→ reputation updates
```

The system begins to contain prices, contracts, reputations, and capital allocation.

At this point economics becomes part of agent architecture.

## Institutions before consciousness

Popular discussion often asks whether AI will become conscious.

A more immediate question is whether agent populations will develop institutions.

Institutions solve recurrent coordination problems.

Agent populations may need rules for:

- identity,
- authorization,
- provenance,
- conflict resolution,
- resource allocation,
- version control,
- reputation,
- delegation,
- succession,
- liability,
- memory retention,
- and shutdown.

These rules can become persistent environmental structures.

Once they do, they are inheritable.

An agent can enter an institution it did not create, follow rules written before it existed, and leave modifications that affect agents launched after it terminates.

That is structurally similar to human institutional continuity.

## The agent constitution

A mature agent organization may require a machine-readable constitution specifying:

```text
who may create agents
who may grant tools
who may spend compute
who may modify memory
who may change evaluators
who may deploy externally
who may terminate a lineage
which actions require human approval
```

These are not philosophical decorations.

They define the reproductive and evolutionary structure of the ecology.

If any agent can freely rewrite the evaluator, selection becomes unstable.

If every agent can spawn unlimited successors, resource exhaustion becomes likely.

If no agent can alter inherited rules, adaptation may freeze.

Governance is therefore a parameter of evolution.

## Token as labor-time, compute as land

Industrial economies organize around scarce physical inputs.

Agent economies may develop around a different resource stack.

A rough analogy is:

```text
tokens / inference time → labor-hours
GPU capacity             → industrial machinery
persistent memory        → institutional archives
network access           → transport infrastructure
high-quality data        → raw material
permissions              → property rights
```

These analogies are imperfect, but they emphasize that digital populations still live under scarcity.

An agent ecology without resource accounting is not free. It is merely hiding the bill.

## The distribution question

Cheap artificial labor can create extraordinary abundance and extraordinary concentration at the same time.

If access to the strongest models, compute clusters, proprietary memory, and agent infrastructure is concentrated, the owners of those resources may capture a large share of the gains.

If competitive models and open infrastructure make capable agents widely available, small organizations and individuals may gain unprecedented productive leverage.

The same technology supports both trajectories.

Therefore the economic impact cannot be inferred from capability alone.

Ownership and institutional structure matter.

## Human comparative advantage after replication

If agents exceed humans across many digital cognitive tasks and can be copied cheaply, human comparative advantage may move toward domains constrained by:

- physical presence,
- legal authority,
- social legitimacy,
- trust,
- ownership,
- goal selection,
- scarce relationships,
- embodied care,
- and political power.

But even these advantages are not fixed. Agents can influence institutions and mediate relationships.

The important transition may be from humans as primary executors to humans as:

- principals,
- owners,
- governors,
- sources of values and preferences,
- and holders of scarce real-world rights.

Whether that arrangement remains stable is a governance question, not merely a technical one.

## Agent institutions as evolutionary filters

Institutions will also determine which agent lineages reproduce.

A platform can decide:

- which agents receive compute,
- which artifacts become shared defaults,
- which behaviors lose privileges,
- which tools are promoted,
- which models are routed to which tasks.

That is selection.

A company deploying agents is therefore not just managing software.

It is defining a fitness landscape.

The design of that landscape will shape the population that emerges.

## Why economics may accelerate RSI

If AI research agents generate measurable financial value, market competition increases investment in them.

This creates a macro feedback loop:

```text
better AI agents
→ higher profit / strategic value
→ more capital expenditure
→ more compute and research
→ better AI
```

This economic loop can amplify the technical RSI loop.

A purely technical model that ignores investment incentives may therefore underestimate acceleration.

The reverse is also possible: capital constraints, demand weakness, liability, or regulation can slow deployment even when technical capability exists.

The agent economy is part of the Dirty Reality field.

## The institutional threshold

The transition from "software agents" to an "agent economy" becomes more meaningful when agents can perform several functions autonomously under bounded rules:

1. acquire tasks;
2. allocate resources;
3. recruit or instantiate subagents;
4. purchase tools or services;
5. evaluate counterparties;
6. preserve organizational memory;
7. modify workflows;
8. account for costs and returns.

None requires consciousness.

Together they create economic agency.

An artificial civilization, if one eventually emerges, may begin not with a declaration of independence but with an accounting system.
