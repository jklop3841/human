# 00 — Project Charter

## 1. Originating human intent

The project originates from a human capability that should remain explicit rather than being optimized away:

> Human beings can deliberately notice structures in the physical and social world, select surprising ones, and hand them to AI even when AI would not have independently chosen to inspect those structures.

The purpose is to exploit this human initiative.

The owner does **not** need to personally engineer every resulting system. His highest-leverage role is discovery, selection, abstraction direction, and cross-domain provocation.

## 2. Core thesis

Large models possess broad knowledge, but broad knowledge does not imply uniform search.

When asked to design Agent systems, models may repeatedly converge on high-frequency human/software priors:
- manager / worker;
- planner / executor;
- supervisor / subagent;
- memory / tool / router;
- company-like hierarchy;
- conventional workflow orchestration.

The Atlas intentionally introduces **non-default structural priors** drawn from systems that survived or emerged under very different constraints.

Examples:
- insect colonies;
- fungal networks;
- immune systems;
- coral reefs;
- cephalopod nervous systems;
- slime molds;
- forests;
- predator-prey ecologies;
- distributed human institutions;
- markets;
- monasteries;
- shipping networks;
- legal systems;
- cities;
- nomadic societies.

## 3. Target artifact

The long-term artifact should become three things simultaneously:

### A. Human-readable Atlas
A “natural history of possible intelligence structures.”

### B. Machine-readable corpus
Structured records that a model can search, combine, score and transform.

### C. Generativity benchmark
A protocol that tests whether the corpus actually changes architecture generation.

## 4. Human/Agent division of labor

### Human should own
- what phenomena are worth collecting;
- first-order intuition;
- surprising cross-domain associations;
- philosophical direction;
- naming;
- curation;
- rejection of sterile or obvious entries.

### Agent should own
- literature support;
- abstraction cleanup;
- formalization;
- primitive extraction;
- composition;
- counterexamples;
- falsifiability;
- implementation proposals;
- sandbox experiment design;
- archive maintenance.

## 5. Non-negotiable epistemic boundary

Every record must distinguish:

1. **Observed** — supported real-world mechanism.
2. **Abstracted** — domain-independent structural interpretation.
3. **Hypothesized** — possible Agent mapping.
4. **Composed** — interaction with other primitives.
5. **Tested** — supported or rejected by experiment.

Never collapse these levels.
