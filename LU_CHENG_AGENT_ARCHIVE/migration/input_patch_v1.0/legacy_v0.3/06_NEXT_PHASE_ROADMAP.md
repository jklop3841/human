# 06 — Next Phase Roadmap

## v0.3 → v0.4 objective
Move from a compelling concept to a measurable research system.

## P0 — Preserve provenance
- attach original/raw observations;
- mark human vs model source;
- store source citations;
- separate evidence from abstraction.

## P1 — Build structured corpus
Create machine-readable records for:
- observations;
- primitives;
- compositions;
- architecture species;
- experiments.

## P2 — Primitive graph
For every primitive record:
- parents;
- compatible primitives;
- conflicting primitives;
- required environmental conditions;
- likely failure modes;
- nearest known engineering concepts.

## P3 — Controlled benchmark
Run baseline vs Atlas vs placebo across several models.

Do not compare prose quality.
Compare architecture distributions.

## P4 — Expand domains
Priority candidates:
1. fungi;
2. immune system;
3. octopus / distributed nervous systems;
4. forests / succession;
5. human institutional structures.

## P5 — Architecture evolution archive
Create a versioned lineage graph:
- parent priors;
- mutations;
- model author;
- test outcomes;
- rejected branches;
- rediscovered known designs.

## P6 — Minimal implementations
Only prototype top-scoring species.

A prototype must answer:
- what property are we testing?
- compared to what baseline?
- what metric changes?
- what result would falsify the claim?

## Stop conditions
Do not expand indiscriminately when:
- entries become poetic analogies;
- source mechanisms are poorly supported;
- generated architectures converge back to conventional patterns;
- no measurable prior effect is found;
- corpus growth exceeds curation quality.
