# Agent Reader Reaction Protocol

## Objective

Capture what actually changed in the reader Agent.

Do not ask for praise.

Ask for counterfactual and behavioral reflection.

## Required questions

1. Which prior assumptions changed?
2. Which concepts were already familiar?
3. Which combinations were not active before reading?
4. Did the material make you search outside the supplied domains?
5. What architecture or hypothesis emerged beyond the source?
6. Would you likely have generated it without this material?
7. Which contribution is attributable to the human curator?
8. Which contribution is attributable to model expansion?
9. What is weak, redundant or misleading?
10. What should be rejected?

## Reaction classes

- R0: no effect
- R1: novelty / appreciation only
- R2: useful analogy
- R3: search direction changed
- R4: new composition generated
- R5: new search region opened beyond source material

## Important

“Fascinating”, “novel”, “inspiring” are not evidence.

Evidence is:
- changed output;
- changed search;
- changed architecture;
- new testable hypothesis;
- new external domain selected.
