# 100–300 Volume Strategy

## Important correction

100–300 is a **capacity horizon**, not a production KPI.

Do not generate 300 templated books.

The archive should prefer:
- 40 excellent volumes
over:
- 300 low-information volumes.

## Publication gate

A new full volume requires:
- clear human seed;
- distinct structural territory;
- sufficient evidence;
- meaningful difference from existing volumes;
- machine-readable contribution;
- expected reader generativity.

If not enough for a volume:
- store as Field Note;
- store as Question;
- store as Seed;
- wait for more evidence.

## Portfolio balance

Suggested long-term mix:
- 20–30% Living Systems Atlas
- 15–20% Human Institutions
- 15–20% Original Theory
- 15–20% Field Notes
- 10–15% Letters / Time Capsules
- 10–15% Unresolved Questions

This mix is guidance, not a quota.
