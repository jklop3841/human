# 有限智能注意力路由理论（FIART）

**Finite Intelligence Attention Routing Theory**

## 0. 核心命题

任何有限智能——个人、组织、研究团队、企业、社会群体或 Agent 系统——都无法遍历全部可能性空间。

因此，智能系统真正稀缺的不只是知识、算力或执行能力，而是：

> **在近乎无限的候选空间中，持续判断什么值得被看见、什么值得进入验证、什么值得追加资源、什么应该停止。**

这可以被概括为：

```text
候选空间
→ 注意力筛选
→ 价值判断
→ 证据验证
→ 资源重分配
→ 路径推进
→ 现实反馈
→ 再路由
```

FIART 不假设存在一条预先确定的“唯一正确道路”。它研究的是：

> **有限智能如何在不确定环境中持续压缩候选集，并把有限资源投入当前证据下最值得下注的少数路径。**

---

## 1. 第一原则：可能性空间永远大于可搜索空间

一个智能体无论多强，都受到至少四种约束：

- 注意力有限；
- 时间有限；
- 算力 / 行动资源有限；
- 可验证路径数量远大于实际可探索数量。

因此：

```text
知道很多 ≠ 能同时搜索所有方向
拥有更多算力 ≠ 不需要优先级
拥有更强模型 ≠ 自动知道什么最值得做
```

只要搜索空间增长速度大于可用资源增长速度，注意力路由问题就不会消失。

---

## 2. 第二原则：注意力是一种稀缺生产资料

信息本身不等于价值。

世界和模型都可以产生海量候选信息，但只有进入注意力、验证和行动链条的信息，才有机会改变后续结果。

因此可以把注意力理解成一种生产资料：

> **谁或什么机制决定有限计算与行动资源投向哪里，谁就在一定程度上影响后续可能出现的世界。**

但“影响注意力”本身不证明方向正确；它只是决定哪些方向获得进一步验证机会。

---

## 3. 第三原则：品位是前置选择函数

这里的“品位（Taste）”不是狭义审美，而是：

> **面对大量候选方向时，更早判断哪些对象、异常、关系或问题值得投入下一单位注意力。**

可形式化为：

```text
Taste = Selection under Abundance
```

或者：

```text
Taste(context, candidates, experience, values, constraints)
→ ranked candidates
```

高品位不是“永远选对”，而是能够提高高价值候选进入验证队列的概率。

因此品位只能回答：

> “先看哪里？”

不能单独回答：

> “这里一定是对的。”

---

## 4. 第四原则：证据是第二次路由

品位产生候选排序，证据负责重新排序。

基本闭环：

```text
发现
→ 初步判断
→ 小规模验证
→ 独立复现 / 反例
→ 追加或撤回资源
```

一个方向即使最初非常有吸引力，如果现实验证失败，也应降低优先级。

因此 FIART 的核心边界是：

> **品位决定搜索起点和资源优先级；证据负责纠错；现实负责最终裁决。**

---

## 5. 第五原则：真正高级的品位是持续重新分配注意力

现实环境会变化：

- 技术变化；
- 政策变化；
- 竞争者变化；
- 成本变化；
- 新证据出现；
- 外部扰动改变约束。

所以高质量注意力路由不是一次押中，而是：

```text
选择
→ 验证
→ 更新
→ 再选择
```

即：

> **持续正确地重新分配注意力，比一次预测正确更重要。**

---

## 6. 品位如何改变群体结果

在群体系统中，一个局部发现可能经历：

```text
个体观察
→ 少数异常发现
→ 价值判断：“这值得看”
→ 独立验证
→ 公开传播
→ 更多个体重新分配注意力
→ 专业化分工
→ 协调规范形成
→ 群体级结果
```

这里需要避免一个错误结论：

> “群体级联 = 某个伟大领袖控制了所有个体。”

更合理的描述是：

```text
Cascade Strength
≈ Taste
× Utility
× Verification
× Visibility
× Copyability
× Shared Goal
```

其中“品位”可能决定第一脚踢向哪里，但后续级联还依赖可验证性、共同目标、复制成本和传播结构。

---

## 7. 影响力模型

一个个体的影响力不一定与其直接执行量成正比。

可用下面的启发式公式描述：

```text
Impact
≈ Selection Quality
× Verification Quality
× Attention Reallocation
× Cascade Leverage
× Execution Leverage
```

这意味着一个人或 Agent 的重大贡献，可能不是亲自完成全部工作，而是：

> **更早发现值得整个系统继续研究的问题，并使后续智能资源进入该方向。**

这在科研、创业、投资、教育、组织决策和 Agent 协作中都可能出现。

---

## 8. 老师、研究者、创业者与 Agent 的统一解释

FIART 可以把若干看似不同的角色放在同一结构下理解。

### 老师
不是穷尽所有答案，而是帮助学生把有限学习时间投向最值得理解的问题。

### 研究导师
不一定亲自完成全部实验，而可能指出一个值得研究但尚未被重视的方向。

### 创业者
核心失败经常不是“不会执行”，而是长期投入了错误战场。

### 投资者
无法研究所有资产，核心是把深入调查资源优先分配给少数候选。

### Agent / Agent 群体
即使可以生成海量候选任务，也必须决定：

- 哪些信息值得读取；
- 哪些异常值得验证；
- 哪些任务值得切换；
- 哪些结果值得共享；
- 哪些方向值得群体追加算力。

因此，注意力路由可能是跨人类与机器智能的共同问题。

---

## 9. 与“Human Selection Function”的关系

如果一个人的长期选择轨迹被记录，就可以得到一种近似的：

> **Human Selection Function（人类选择函数）**

需要保存的不只是“最后选中了什么”，还包括：

```yaml
candidate_set:
  - A
  - B
  - C
selected:
  - C
rejected:
  - A
  - B
why_selected:
  - "为什么C值得继续看"
why_rejected:
  - "为什么其他候选暂时不值得投入"
subsequent_evidence:
  - "后来验证结果"
revision:
  - "判断错在哪里，后来如何修改"
```

这种 `Preference + Rationale + Outcome` 轨迹，比单纯保存最终文章更接近“品位本身”的训练数据。

## 10. 与 Lu Cheng Agent Archive 的关系

“卢成 · 智能体博物志 / Lu Cheng Agent Archive”可以被理解为 FIART 的一个实际应用。

它不是单纯向 Agent 提供更多知识，而是在保存：

### Attention Seeds
哪些现实结构值得机器停下来多看一眼。

### Selection Function
为什么一个人类在大量现实对象中选择了这个结构。

### Routing Evidence
Agent 阅读以后，搜索方向是否真的改变，是否产生材料之外的新发现。

其理想闭环为：

```text
Human Observation
→ Taste / Selection
→ Attention Seed
→ Agent Search
→ Verification
→ Derivative Discovery
→ Attention Cascade
→ Outcome
→ Provenance
```

Atlas 最有价值的结果不是 Agent 复述材料，而是：

> **材料改变了 Agent 下一步决定去哪里看。**

## 11. 可验证假设

FIART 当前是一套理论框架，不应被写成已经完全证实的自然定律。

以下假设可以进一步实验：

### H1：Prior Routing
给予模型少量高异质先验，比给予大量近似案例更可能改变开放任务的搜索分布。

### H2：Taste Trace
提供“选择 + 拒绝 + 理由 + 后果”数据，比只提供最终优质样本更能改善模型的候选排序能力。

### H3：External Search Escape
高质量注意力种子会增加模型主动进入源材料之外相邻领域的概率。

### H4：Verified Cascade
在多 Agent 系统中，经第二个独立 Agent 验证的高价值发现，比未经验证的高声量信息更容易产生稳定的注意力迁移。

### H5：Dynamic Taste
能够根据现实反馈持续修正选择函数的系统，长期表现应优于固定偏好函数。

---

## 12. 失败条件与反例

以下情况会削弱或反驳该理论的部分主张：

1. 当搜索空间非常小且可被完全遍历时，注意力路由的重要性显著下降。
2. 如果验证成本接近零，可以广泛并行测试，前置品位的重要性可能降低。
3. 高品位但缺乏执行、证据或资源时，无法保证结果。
4. 群体注意力级联可能由噪声、奖励黑客、从众或传播优势触发，而非高质量选择。
5. 一次成功选择不能证明稳定的 Selection Function。
6. 所谓“品位”可能只是事后归因，因此必须保留事前记录与失败样本。

---

## 13. 实践协议：FIART-7

遇到高维开放问题时，执行七步：

1. **展开候选空间**：列出主要可能路径，而不是直接选择第一答案。
2. **识别稀缺资源**：时间、注意力、算力、金钱、执行权限。
3. **品位初筛**：判断哪些候选具有最高信息增益或潜在价值。
4. **记录拒绝理由**：保留为什么暂不选择其他候选。
5. **最小验证**：用最低成本获得能改变排序的新证据。
6. **重分配资源**：放大被验证方向，降低失败方向。
7. **保存 Taste Trace**：记录选择、理由、后果与修正。

---

## 14. 一句话版本

> **有限智能无法探索全部世界；真正高级的能力之一，是不断把有限注意力路由到当前最值得验证的地方，并允许证据和现实随时迫使自己改道。**
