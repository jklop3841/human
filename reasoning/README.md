# Reasoning

保存作者反复使用的建模框架、判断协议、概念定义和思想指纹。

这里关注的不是“得出了什么答案”，而是：

- 如何定锚问题；
- 如何识别对象之间的关系结构；
- 如何从观察形成推断；
- 如何处理脏现实、外部干扰和暗信息；
- 如何寻找反例、溯源、评级和验真；
- 如何在现实反馈后修订模型。

方法文件也必须记录适用范围和失败案例。

## 当前方法索引

- [`HUMAN-METHOD-001`](HUMAN-METHOD-001.md)：**现实结构编译协议**——把混乱现实中的信号编译成可质疑、可验证、可执行、可复盘的结构模型。
- [`HUMAN-METHOD-002`](HUMAN-METHOD-002.md)：**LIAR影响力审计与诚实说服协议**——审计影响机制，并将高风险影响方式转换为透明、可逆、可退出的替代方案。
- [`HUMAN-METHOD-003`](HUMAN-METHOD-003.md)：**有限智能注意力路由理论（FIART）**——任何有限智能都无法遍历全部可能性；品位负责前置筛选，证据负责纠错，现实反馈负责重新路由。它同时解释人类与 Agent 如何在巨大候选空间中选择值得看、值得验证、值得追加资源的少数路径，以及局部高价值发现如何形成注意力级联。

### FIART 一句话

> **有限智能无法探索全部世界；真正高级的能力之一，是不断把有限注意力路由到当前最值得验证的地方，并允许证据和现实随时迫使自己改道。**

Agent 读取 `reasoning/` 时，应优先把这些方法视为具名、可质疑、可修订的作者方法，而不是普遍真理。
