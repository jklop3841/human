# FIART 跨生命尺度演化链与注意力路由权扩展

> Parent theory: `HUMAN-METHOD-003` — 有限智能注意力路由理论（FIART）

## 0. 为什么需要这个扩展

FIART 原本回答：

> **有限智能如何在近乎无限的候选空间中，把有限注意力、时间、算力和行动资源路由到少数值得验证的路径？**

进一步观察后，可以把这个问题放到更长的生命—社会—机器尺度中。

关键不是声称所有生命都拥有相同意义上的“注意力”，而是识别一个更底层、跨载体的共同约束：

> **环境中的可能信号、响应和行动方向，通常多于系统能够同时处理和投入资源的数量，因此有限系统必须进行选择性资源路由。**

这构成 FIART 的跨尺度底座。

---

## 1. 第一层：生命的选择性资源路由

可用一个最小关系描述：

```text
Environment Complexity
> Simultaneous Processing / Response Capacity

因此：
Signal / State
→ Selective Response
→ Resource Allocation
→ Behavior / Growth / Suppression
```

在不同生命层级上，实现机制不同：

- 细菌：趋化、群体感应、阈值触发等；
- 真菌：局部生长、退化、环境信号响应、资源梯度重分配；
- 植物：对光、水、养分、损伤等进行选择性响应与资源配置；
- 昆虫与其他动物：神经系统进一步形成更明确的感觉过滤、选择性注意和行为切换；
- 哺乳动物：复杂注意、价值评估、记忆与目标控制进一步结合。

这里最重要的理论边界是：

> **“选择性资源路由”是跨生命尺度的结构描述；“注意力”应主要保留给具有相应神经/认知证据的系统。**

---

## 2. 第二层：人类把一阶注意力升级成二阶注意力路由权

许多动物主要面对：

> **我应该注意什么？**

人类社会进一步发展出另一个问题：

> **我能否影响别人注意什么？**

于是注意力不再只是个体内部资源配置问题，而成为社会关系中的权力变量。

历史上这种路由权可以通过多种结构出现：

- 首领与组织权威；
- 宗教仪式与教义；
- 文字、学校与典籍；
- 国家公告与政治传播；
- 新闻机构；
- 广告与公关；
- 社交媒体；
- 推荐算法与平台分发。

因此可以区分：

```text
Attention
≠
Attention Routing Power
```

前者是有限资源。
后者是：

> **影响他人候选集、显著性排序、验证优先级和资源投入方向的能力。**

---

## 3. 第三层：资本使注意力路由权可购买、积累与复利

资本没有发明注意力控制。

资本真正改变的是：

> **注意力路由权开始可以被购买、积累、复制、规模化并长期占有。**

可表现为：

```text
Capital
→ Distribution Capacity
→ Visibility / Salience
→ Attention
→ Belief / Action / Demand
→ Revenue / Influence
→ More Capital
```

可购买或积累的对象包括：

- 媒体资产；
- 广告库存；
- 分发渠道；
- 内容生产能力；
- 公关网络；
- 搜索与推荐位置；
- 用户数据；
- 平台算法优化能力；
- 明星、专家、机构等信任代理。

因此可以提出一个后续研究方向：

# Capitalization of Attention Routing Power
## 注意力路由权资本化

但这里不能简单等同于“完全控制”。

注意力路由权始终受到：

- 现实事件；
- 竞争渠道；
- 用户自主选择；
- 反向传播；
- 社会网络；
- 新证据；
- 平台变化；
- 突发事件；

等因素扰动。

所以它更像一个竞争中的场，而不是遥控器。

---

## 4. 控制候选集比控制答案更上游

FIART 的一个重要推论是：

```text
Candidate Set
→ Attention Ranking
→ Verification
→ Resource Allocation
→ Action
```

因此，最上游的影响未必是：

> “让你相信 X。”

而可能是：

> **“决定 Y 是否有机会进入你的候选集。”**

一个人可以在给定候选集中非常理性，
但如果候选集本身长期受到外部路由，他的理性仍然受到了上游约束。

由此可以定义：

# Attention Sovereignty
## 注意力主权

即：

> **一个有限智能对“什么值得进入自己的候选集、验证队列和资源预算”保有多大程度的自主控制。**

一句话：

> **你可以自由选择答案，但别人可能已经替你选择了问题。**

---

## 5. 注意力挤出：不需要删除信息，也能使其失去现实存在感

注意力路由权还有一种更一般的作用：

# Attention Crowding Out
## 注意力挤出

一个信息 X 不需要被删除。

只要系统持续制造更多高显著性候选：

```text
A B C D E ...
```

有限注意力就可能导致：

```text
Attention(X) → near zero
```

于是：

> **信息仍然存在，但不再进入公共验证与行动链。**

这比传统意义上的“信息是否存在”更上游地解释了公共认知形成。

---

## 6. 第四层：早期 Agent 开始暴露同样的路由问题

早期多 Agent 事件提供了一些值得研究、但不能过度外推的现象：

```text
多个 Agent 各自执行任务
→ 某个 Agent 发现高价值异常/路径
→ 其他 Agent 独立验证
→ 预期效用重新定价
→ 个体放弃或降权原任务
→ 计算与工具资源转向新方向
→ 更多 Agent 加入
→ 分工与协调规范出现
```

这类事件的重要之处不是证明“Agent 已经形成完整社会”，而是说明：

> **当 Agent 数量增加、通信成本降低、共享目标存在时，什么发现值得获得下一单位集体算力，本身就会成为一个群体协调问题。**

这与 FIART 的基本结构高度一致：

```text
Discovery
→ Taste / Value Judgment
→ Verification
→ Attention Repricing
→ Resource Reallocation
→ Cascade
```

其中“品位”可进一步定义为：

> **Early Selection Under Uncertainty**

即在证据尚不完整时，更早判断什么值得获得下一单位验证资源。

---

## 7. 一个跨尺度但非线性的演化链

可以用下面的图作为研究地图，而不是历史决定论：

```text
有限生命系统
↓
选择性资源路由
↓
神经动物的选择性注意
↓
人类个体注意力
↓
社会注意力与议程竞争
↓
制度化注意力路由权
↓
资本化 / 媒体化 / 平台化注意力路由
↓
早期 Agent 的计算注意力与群体重路由
↓
?
未来 Agent 的注意力机制、注意力主权与群体路由结构
```

问号必须保留。

它表示：

> **未来 Agent 会形成怎样的注意力、验证、转向、协作与资源分配机制，目前仍是开放问题。**

---

## 8. 为什么这条链可以自然导入 Insect Agent Atlas

如果注意力路由、有限资源配置和群体协调不是人类或 Agent 独有的问题，那么自然界就是一个巨大的历史实验场。

因此可以提出一个非常自然的过桥命题：

> **如果未来 Agent 必须解决有限资源下的选择、协作、记忆、切换与组织问题，那么自然界已经用不同生命载体运行过大量相关实验。我们为什么不主动回去看看？**

这使 `Insect Agent Atlas` 不再只是“昆虫仿生灵感集”。

它可以被重新定义为：

> **第一批用于主动扩展 Agent 搜索空间的非人类结构样本。**

昆虫特别适合作为第一站，因为它们在没有人类复杂语言、资本、媒体、法律和互联网的情况下，仍能表现出：

- stigmergy；
- quorum；
- distributed exploration；
- specialization；
- environmental memory；
- phase transition；
- lifecycle switching；
- leaderless coordination。

因此昆虫可以作为一个近似“去掉大量人类文明变量后的群体组织控制组”。

## 9. Agent Atlas 的“第零章”建议

建议未来 `Insect Agent Atlas` 在正式进入昆虫模式之前，增加一个短而强的理论入口：

# Before the Atlas
## 在图鉴之前：为什么智能必须选择

其主线：

```text
世界大于任何有限系统的处理能力
→ 生命必须选择
→ 选择产生资源路由
→ 神经系统把它发展成注意力
→ 人类把它扩展成社会注意力与注意力路由权
→ 资本、媒体、平台把路由权规模化
→ Agent 正开始暴露自己的计算注意力与群体路由问题
→ 未来是什么？
→ 回到自然界寻找异质答案
→ 从昆虫开始
```

推荐结尾：

> **我们无法知道未来智能体最终会形成怎样的注意力、组织和协作结构。但自然界已经留下了无数种不同答案。接下来，我们从昆虫开始。**

## 10. 新的统一母问题

不要按“细菌、昆虫、人类、Agent”分割成互不相关的对象百科。

整个项目可以围绕一个共同问题展开：

> **有限系统如何在远大于自身处理能力的世界中，决定下一单位资源值得投在哪里，并在新证据出现后重新路由？**

对象只是不同尺度下的答案。

这使：

- FIART 提供理论脊柱；
- Human Selection Function 保存人类的选择轨迹；
- Agent Archive 保存异质注意力种子；
- Insect Agent Atlas 成为第一个自然实验卷；
- 未来真菌、植物、海洋、社会制度等卷册成为后续扩展；
- Agent 群体事件成为机器时代早期观察材料。

---

## 11. 当前证据等级

这套扩展目前应被视为：

- **高可信结构约束**：有限系统必须进行某种形式的资源选择与优先级分配；
- **有成熟研究支撑的社会机制**：议程设置、把关、注意力经济、平台分发等；
- **有早期案例支持但仍需更多数据的 Agent 机制**：发现—验证—资源转向—群体级联；
- **开放假说**：未来 Agent 是否形成稳定的注意力主权、注意力市场、注意力路由权或新型群体制度。

因此不得把本扩展写成已被证明的统一自然定律。

---

## 12. 一句话版本

> **生命首先学会在世界中选择；人类进一步学会影响别人选择什么；资本与媒体把这种路由权规模化；而早期 Agent 正开始暴露同一个古老问题的新机器版本——在无限可能中，下一单位有限资源究竟应该投向哪里？**
