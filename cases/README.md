# Cases

保存用于支持、挑战或校准观点的现实案例。

每个案例应尽量区分：公开事实、作者观察、第三方说法、作者解释和仍未知的信息。案例不得仅因符合观点而入库；负例与失败样本具有同等优先级。

Human Casebook 的目标不是寻找“证明 Human 理论正确”的故事，而是建立：

`事件 → 证据 → 结构分析 → 竞争解释 → 纠错 → 支持/反例`

第一卷共 12 个跨领域案例；第二卷开始强制加入成功案例与反例，避免失败样本选择偏差。
