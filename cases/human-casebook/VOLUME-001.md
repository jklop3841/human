## 卷首说明

Human 体系已经形成一条主干：

`人 → 群体 → 机构 → 文明`

以及一条底层结构链：

`关系 → 结构 → 场 → 路径 → 结果`

但如果任何现实事件都可以被解释成“脏现实作用力”，这个框架就会退化成万能解释器。

所以本卷增加一条更严格的规则：

> **先让现实拥有解释权，再让理论拥有命名权。**

每个案例先还原公开事实，再看 Human 模型能解释多少；如果存在更强的竞争解释，必须保留；如果案例不支持模型，也必须记录。

# CASE-001｜Brandon Mayfield 指纹误认

**领域：** 司法 / 执法 / 法证  
**时间：** 2004–2011  
**机构：** FBI、FBI Laboratory、西班牙国家警察、法院  
**理论结果：** `partially_supports`  
**证据等级：** `E4`

### 1. 事实基线

2004 年马德里列车爆炸案后，FBI 实验室将现场一枚潜指纹错误识别为美国律师 Brandon Mayfield。Mayfield 随后被作为 material witness 拘押。西班牙警方后来确认该指纹属于另一名阿尔及利亚男子，FBI 撤回识别结果。

美国司法部监察长后续审查指出，问题并非简单的“某个坏人故意陷害”，而是多个环节叠加：检验过程出现错误、分析人员对相似细节过度依赖、忽略或合理化不一致之处，并在西班牙警方给出 negative conclusion 后，没有充分重新打开错误可能性。OIG 还指出，实验室对自身专业能力的过度自信削弱了外部异议的纠错作用。

### 2. 关系结构

`现场证据 → 专家解释 → 实验室权威 → 执法调查 → 法院权限 → 个体自由`

这里最重要的不是“指纹”本身，而是**专业判断进入高权限链条后会被放大**。一个技术判断一旦被组织承认为事实，后续调查信息又可能反过来强化最初判断。

### 3. 脏现实作用力

- 恐怖袭击后的时间压力；
- 专业权威和机构声誉；
- 初始匹配形成的确认偏差；
- 内部同侪验证并不等于真正独立验证；
- 外部异议进入组织后权重不足；
- 调查信息可能反向污染法证解释。

### 4. 偏移机制

Human 视角下，这不是“司法系统天然会制造冤案”，而是：

`初始判断 → 权威确认 → 调查资源围绕判断展开 → 新信息被解释进旧模型 → 异议成本上升`

也就是**证据链开始围绕既有结论自我增重**。

### 5. 竞争解释

最强竞争解释是：现场指纹与 Mayfield 指纹确实存在异常高相似性，即使多名有经验专家也可能发生诚实错误。因此不能把全部原因归结为组织压力或偏见。

### 6. 纠错机制

外部警方异议、OIG 独立调查、标准操作流程重写、文档要求加强、单一潜指纹识别的 blind verification 等，构成了系统重新引入独立性的方式。

### 7. 对 Human 的修正

这个案例支持“高权限专业判断需要独立纠错”，但也提醒 Human：**并非所有错误都来自激励扭曲，纯粹的感知与方法误差本身就是重要变量。**

# CASE-002｜Challenger：工程异议如何被组织过滤

**领域：** 航天 / 工程 / 官僚组织  
**时间：** 1981–1986  
**机构：** NASA、Marshall Space Flight Center、Morton Thiokol  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

1986 年挑战者号航天飞机升空后解体。Rogers Commission 认定直接技术原因是右侧固体火箭助推器接头密封失效，同时明确指出发射决策过程存在严重缺陷：关键决策者没有完整获得 O-ring 问题历史、承包商最初反对低温发射的意见，以及工程师仍然存在的反对意见。

委员会还批评了一个结构性倾向：一些潜在严重问题被留在较低组织层级内部处理，没有完整向上沟通。

### 2. 关系结构

`工程数据 → 承包商工程师 → 承包商管理层 → NASA 项目管理 → 发射决策`

信息不是不存在，而是在穿过组织层级时发生了**压缩、重新表述和权重变化**。

### 3. 脏现实作用力

- 发射进度压力；
- 管理层与工程师承担的目标不同；
- 客户—承包商关系；
- 历史飞行成功带来的风险正常化；
- 上行信息过滤；
- 技术不确定性在管理层被压缩成“可接受/不可接受”。

### 4. 偏移机制

`异常出现 → 暂时未造成事故 → 异常被重新定义为可接受 → 组织形成历史先例 → 下一次继续放宽`

这是 Human 体系非常典型的**路径依赖 + 成功幸存反向证明安全**。

### 5. 竞争解释

不能把事故简化成“管理层为了进度故意忽视安全”。真实系统还存在技术理解不足、数据样本有限、风险概率难量化等问题。

### 6. 纠错机制

事故调查、密封结构重新设计、安全流程重构、发射准备审查强化，本质上都是增加“异常必须向上传递”的制度权重。

### 7. 对 Human 的修正

这个案例强力支持“机构中的信息不是静态资产，而是沿层级流动时不断变形”的判断。

# CASE-003｜Mid Staffordshire：医疗使命如何被目标系统拉偏

**领域：** 医疗 / 医院 / 监管  
**时间：** 2005–2009；2013 公共调查  
**机构：** Mid Staffordshire NHS Foundation Trust、NHS 监管机构、Department of Health  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

英国 Francis Inquiry 调查了 Mid Staffordshire NHS Foundation Trust 的严重护理失败。官方调查和政府回应指出：Trust Board 未能倾听病人和员工，没有纠正长期低标准文化；更广泛监管体系也没有及时保护患者。

公开回应特别总结了三个结构问题：对财务与数字的关注压过患者照护；责任不断向其他组织转移；面对不利信息时出现防御和自我安慰倾向。Francis 报告后提出 290 项建议，涉及透明度、护理标准、人员配置、监管和公开责任。

### 2. 关系结构

`患者 → 一线医护 → 医院管理 → NHS 目标与财务 → 外部监管 → 政府`

医院的纸面使命是照护患者，但医院同时被财务、等待时间、资格评估、组织评级等多个系统约束。

### 3. 脏现实作用力

- 有限人员与无限需求；
- top-down targets；
- 财务平衡压力；
- 基金会资格和组织声誉；
- 一线人员沉默或认为发声无效；
- 监管者彼此假设“别人正在负责”；
- 正面指标对负面现场信息形成遮蔽。

### 4. 偏移机制

`医疗使命 → 可量化目标 → 目标成为管理语言 → 不容易量化的照护体验降权 → 投诉和一线信号无法穿透指标层`

这是“**指标不是使命，但指标逐渐取得使命的操作权**”。

### 5. 竞争解释

不能把所有医院问题都归咎于 KPI。人员能力、具体管理失误、临床复杂度、长期资源不足同样重要。

### 6. 纠错机制

Duty of candour、更加透明的 staffing reporting、投诉和事故公开、监管改革，本质都是把被压低的信息重新接回决策系统。

### 7. 对 Human 的修正

支持机构偏移模型，但应加入一条：**指标只有在缺少反向质量信号时才更容易替代使命；指标本身也可以成为纠错工具。**

# CASE-004｜Silicon Valley Bank：银行并不是只由资产负债表决定

**领域：** 银行 / 金融监管 / 信任  
**时间：** 2019–2023  
**机构：** Silicon Valley Bank、Federal Reserve、California DFPI、存款人网络  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

美联储 2023 年复盘认为，SVB 董事会和管理层未能有效管理风险；银行业务高度集中、依赖大量未保险存款，并在快速增长过程中积累利率与流动性风险。监管者也没有充分认识风险严重程度，在识别部分问题后未推动足够快的纠正。

2023 年 3 月 9 日银行遭遇超过 400 亿美元存款流出，次日还有更大规模提款请求预期，随后被关闭。

### 2. 关系结构

`科技行业现金 → 银行存款 → 长久期资产 → 利率变化 → 账面损失 → 市场信息 → 存款人预期 → 提款 → 流动性现实`

这里出现一个关键反馈：

`对银行可能不安全的信念 → 提款 → 银行流动性下降 → 银行真的更不安全`

信心不是“虚拟情绪”，而是可以通过集体行为改变资产负债状态的变量。

### 3. 脏现实作用力

- 高度集中客户网络；
- 未保险存款比例高；
- 短期收益与风险管理激励不一致；
- 银行增长速度快于治理能力；
- 监管迁移和监管资源匹配滞后；
- 数字银行时代资金迁移速度加快。

### 4. 偏移机制

`增长 → 风险暴露扩大 → 内控滞后 → 监管仍沿旧分类观察 → 市场状态突变 → 网络化存款人同步行动 → 非线性崩塌`

### 5. 竞争解释

利率快速上升本身是巨大外部冲击。不能把失败完全归结为治理问题；没有宏观环境变化，风险可能不会在同一时间显性化。

### 6. 纠错机制

资本/流动性监管、压力测试、风险信息披露、监管分类随规模动态调整、存款保险与流动性工具，都属于降低反馈环爆炸速度的结构工具。

### 7. 对 Human 的修正

这个案例强化了 Human 的“信任场”概念，但需要严格表达为：**预期只有通过资金移动、合同、价格或行为改变系统变量时，才获得现实因果权。**

# CASE-005｜Wells Fargo：当销售数字取代了“服务客户”

**领域：** 公司 / 银行 / 销售管理  
**时间：** 2011–2016 及更早  
**机构：** Wells Fargo、CFPB、OCC、地方监管  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

2016 年 CFPB 对 Wells Fargo 采取执法行动，认定其存在大规模未经客户授权开设存款账户和信用卡等行为。CFPB 明确指出，销售目标和薪酬激励推动员工通过未经授权账户提高销售数字。

### 2. 关系结构

`公司战略 → 销售目标 → 经理考核 → 员工收入/岗位安全 → 客户账户`

纸面使命可能是“为客户提供金融服务”，而实际一线每天面对的可计算命令是：完成多少销售数。

### 3. 脏现实作用力

- 销售配额；
- 奖金；
- 就业压力；
- 管理层数字可见性远高于客户长期损害；
- 大组织中违规行为被拆散到许多一线员工；
- 局部“完成目标”能获得即时奖励，长期法律风险则延迟出现。

### 4. 偏移机制

`使命：服务客户 → proxy：产品数量 → proxy 取得奖励权 → 员工开始优化 proxy → 客户利益成为约束而不是目标`

这就是 Goodhart 型结构最直观的机构案例之一。

### 5. 竞争解释

不能认为所有销售激励都会导致欺诈。核心变量是目标强度、监控方式、惩罚结构、投诉通道和文化，而不是“有 KPI 就必然作恶”。

### 6. 纠错机制

外部执法、客户赔偿、薪酬结构修改、董事会监督、投诉信号上升，都在把客户损害重新变成管理层必须看到的成本。

### 7. 对 Human 的修正

强支持“指标替代使命”，但 Human 应避免把 Goodhart 当作自动定律；更准确的判断是：**proxy 与真实目标偏离、奖励强度高、纠错信号弱时，替代风险快速上升。**

# CASE-006｜Atlanta Public Schools：当“学生学会了什么”变成“考试数字是多少”

**领域：** 教育 / 公共管理 / 考试  
**时间：** 2001–2011  
**机构：** Atlanta Public Schools、学校管理层、Georgia 州教育监督机构  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

Georgia 州调查发现 Atlanta Public Schools 存在广泛考试作弊。调查材料将重要原因指向数据驱动环境下达到目标的压力，并指出一些早期警告长期未得到有效处理。后续 Georgia 建立更强的考试材料 chain-of-custody、异常分数和擦改分析触发调查等机制。

### 2. 关系结构

`教育使命 → 标准化考试 → 学校排名/声誉 → 校长压力 → 教师压力 → 答题卡 → 学生数据`

当“教育质量”无法直接观察时，系统选择考试成绩做代理指标；随后代理指标又进入奖惩体系。

### 3. 脏现实作用力

- 目标压力；
- 学校/管理者声誉；
- 数据驱动问责；
- 多层级绩效传导；
- 早期异常信号被解释掉；
- 学生作为最终对象，却没有同等反馈权。

### 4. 偏移机制

`学习 → 测试成绩代理 → 代理绑定组织生存 → 组织开始优化分数而不是学习`

极端情况下，系统甚至不再“teaching to the test”，而是直接修改测试结果。

### 5. 竞争解释

作弊仍然包含明确个人责任，不能用“结构压力”替行为人免责。结构解释的是为什么违规可以规模化和持续化，不是否认个人选择。

### 6. 纠错机制

独立调查、异常擦改统计、考务链路监控、分数异常自动触发机制，本质是让“过于漂亮的数据”本身也成为风险信号。

### 7. 对 Human 的修正

支持指标替代使命，同时说明：**高质量治理不仅监控低绩效，也必须监控异常高绩效。**

# CASE-007｜9/11 前情报共享失灵：拥有信息不等于拥有认知

**领域：** 情报 / 执法 / 政府协调  
**时间：** 1990s–2001；2004 调查  
**机构：** CIA、FBI、NSA、移民/海关及其他联邦机构  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

9/11 Commission 和美国国会后续审查均把信息共享列为重大问题。委员会指出，美国政府拥有巨大信息存量，但处理、关联和使用这些信息的体系薄弱；不同机构使命、法律权限、文化和“need to know”结构阻碍了信息在需要的位置形成完整图景。

### 2. 关系结构

`情报采集 → 数据库 → 分类权限 → 分析人员 → 跨机构共享 → 行动权限`

这说明：

`数据存在 ≠ 信息可访问 ≠ 信息被关联 ≠ 判断形成 ≠ 有人能行动`

Human 应把“信息”拆成多个状态，而不是把信息看作一种静态资源。

### 3. 脏现实作用力

- 保密需要；
- 部门边界；
- 不同法律权限；
- 机构文化；
- 数据格式和后端基础设施；
- 谁拥有信息、谁承担行动责任并不一致。

### 4. 偏移机制

每个机构在局部规则下都可能合理，但系统整体出现：

`局部保密最优 + 局部权限最优 + 局部数据库最优 → 全局无法连接线索`

这是 Human 的“局部理性 → 全局失效”模型。

### 5. 竞争解释

事后看线索更容易形成完整故事，存在 hindsight bias。不能假设“只要共享就一定能阻止攻击”。

### 6. 纠错机制

从 need-to-know 向 need-to-share 的制度改革、跨机构分析、统一协调结构等，都是在重新设计信息拓扑。

### 7. 对 Human 的修正

强支持“关系结构决定信息是否成为行动能力”，但应持续警惕事后诸葛式过度归因。

# CASE-008｜Hurricane Katrina：灾害把平时隐藏的组织依赖一次性显影

**领域：** 灾害治理 / 政府 / 应急  
**时间：** 2005–2006  
**机构：** FEMA、DHS、白宫、Louisiana、New Orleans、军方、地方应急机构  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

美国国会对 Katrina 的调查描述了广泛的准备、通信、指挥与协同失败。参议院报告指出，长期警告未被充分转化为准备，多层政府在灾害前后都出现领导与协调不足；通信系统在断电和基础设施受损后大量失效，而替代通信准备不足。

### 2. 关系结构

`气象预警 → 地方政府 → 州政府 → 联邦政府 → FEMA/DHS → 军方/救援 → 通信/道路/电力 → 灾民`

灾害不是单点事件，它同时攻击多个原本互为前提的系统。

### 3. 脏现实作用力

- 多层政府权限交叉；
- 谁先行动存在程序与政治问题；
- 通信基础设施也是指挥系统前提；
- 常态流程按“系统仍然基本可用”设计；
- 极端事件下需求速度超过组织协调速度。

### 4. 偏移机制

`通信失败 → 态势感知下降 → 指挥判断下降 → 资源调度错误/延迟 → 现场进一步恶化 → 信息更加混乱`

这是典型的负向反馈放大。

### 5. 竞争解释

Katrina 的自然强度和堤坝失效本身就是巨大外生冲击，不能将全部损失归因于治理。

### 6. 纠错机制

预案重构、跨层演练、备用通信、资源预部署、灾害指挥权清晰化，本质上是为极端状态设计另一套运行结构。

### 7. 对 Human 的修正

Human 应明确：**常态下运行良好的机构，不等于极端状态下仍是同一个系统。** 时间状态必须成为机构模型的一等变量。

# CASE-009｜Texas 2021 冬季风暴：电网和天然气不是两个系统

**领域：** 基础设施 / 电力 / 天然气 / 监管  
**时间：** 2021  
**机构：** ERCOT、电力企业、天然气生产与运输、FERC、NERC  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

2021 年美国南中部极寒事件导致大量发电机组停机、降额或无法启动。FERC/NERC 后续报告指出，冻结问题和燃料问题是主要原因，天然气生产和供应下降又与冻结、电力损失等相互关联。ERCOT 为防止电网整体崩溃实施了大规模轮流停电。

### 2. 关系结构

`天然气生产需要电 → 燃气供给发电机 → 发电机提供电 → 部分燃气设施又依赖电`

因此：

`电力 ↔ 天然气`

不是上下游单向链，而是互相激活的耦合系统。

### 3. 脏现实作用力

- 极端天气低频但高损失；
- winterization 投资成本当下可见、灾难收益长期不可见；
- 多行业监管边界；
- 关键设施识别和停电优先级；
- 每个企业局部成本最优，不等于系统韧性最优。

### 4. 偏移机制

`少量节点失效 → 发电下降 → 断电 → 燃气基础设施受影响 → 燃气供给进一步下降 → 更多发电失效`

这是文明依赖图中的**跨系统正反馈级联**。

### 5. 竞争解释

极端寒冷本身是主触发器，而且并非所有停机都来自制度缺陷。必须区分不可避免损失与可通过 winterization 降低的损失。

### 6. 纠错机制

强制寒冷天气标准、关键组件防冻、燃气—电力协调、极端天气需求预测、关键天然气设施保护等。

### 7. 对 Human 的修正

强支持 BOOK-002 的文明依赖模型，并说明“节点关键性”不能只按一个行业内部衡量，应看跨系统耦合度。

# CASE-010｜Publish or Perish：科学也会被自己的奖励函数塑形

**领域：** 科研 / 大学 / 期刊 / 基金  
**时间：** 长期结构；2018 等研究系统化建模  
**机构：** 大学、研究机构、期刊、基金、晋升制度  
**理论结果：** `partially_supports`  
**证据等级：** `E3`

### 1. 事实基线

科学共同体长期讨论 publish-or-perish 激励。2018 年 Royal Society Open Science 的模型研究讨论了以发表产出奖励科研人员时，如何可能提高粗心或不诚实行为的相对适应度，并与正结果偏好、可重复性问题形成反馈。

这里必须强调：这是模型与广泛元科学研究支持的**风险机制**，不是证明“科研人员普遍造假”。

### 2. 关系结构

`研究 → 论文 → 期刊接受 → 引用/声望 → 职位/基金 → 下一轮研究资源`

真正目标是产生可靠知识，但大量实际资源分配不得不依赖可测量代理：论文数、期刊、引用、项目数。

### 3. 脏现实作用力

- 稀缺岗位和基金；
- 正结果与新颖性的发表优势；
- 失败实验不可见；
- 复制研究收益偏低；
- 评价者没有能力完整复核每项研究。

### 4. 偏移机制

`可靠知识 → 可发表结果代理 → 代理决定资源 → 研究设计适应代理 → 文献可见样本发生选择`

### 5. 竞争解释

科学体系同时具有强大的同行评审、复制、争论和自我修正机制；发表激励并不只有负作用，它也促进产出、公开和竞争。

### 6. 纠错机制

预注册、开放数据、复制研究、结果无关审稿、评价体系改革等，都是减少“发表代理”对研究问题本身的支配。

### 7. 对 Human 的修正

这个案例最重要的提醒是：**机构偏移与机构纠错可以同时存在。** 科学不是因为存在激励缺陷就失去知识生产能力。

# CASE-011｜Engagement Ranking：平台没有“想让人极化”，但目标函数会塑造信息生态

**领域：** 数字平台 / 推荐系统 / 媒体  
**时间：** 2018–2026  
**机构：** 社交媒体平台、推荐算法、用户网络、广告市场  
**理论结果：** `partially_supports`  
**证据等级：** `E3`

### 1. 事实基线

2026 年 Journal of Public Economics 论文建立了用户行为与推荐排名之间的动态反馈模型，并结合美国和意大利调查数据分析 Facebook 2018 年 Meaningful Social Interactions 更新。研究结果支持这样一个机制：提高某些分享型 engagement 信号的权重，在研究条件下可能放大错误信息和意识形态极化。

### 2. 关系结构

`用户偏好 → 点击/分享 → ranking score → 可见度 → 更多用户行为 → 新 ranking data`

平台既观察用户，又通过可见度重新塑造下一轮用户行为。

### 3. 脏现实作用力

- engagement 易测量；
- 用户停留与广告收益可直接计价；
- 极端用户可能产生更强互动；
- 推荐系统的局部目标与社会外部性不是同一目标；
- 个体选择经过算法聚合后形成新的多数感知。

### 4. 偏移机制

`“让用户看到更可能互动的内容” → 高互动内容得到更多曝光 → 曝光创造更多互动数据 → 系统进一步确认该内容值得曝光`

这是算法版的结构反馈环。

### 5. 竞争解释

极化并非只由算法产生。自我选择、既有政治分裂、媒体生态、用户网络同质性都可能产生同类结果。不同算法和平台环境下效果也可能不同。

### 6. 纠错机制

多目标排序、质量/可信度信号、用户控制、外部审计、实验透明度、对社会外部性的指标化，都是可能的纠偏路径。

### 7. 对 Human 的修正

应避免人格化平台。更准确的语言不是“平台想制造愤怒”，而是：**某个优化目标在特定用户分布和反馈结构下可能产生平台本身未必直接追求的稳定结果。**

# CASE-012｜Flint Water Crisis：当责任分布在多个机构之间

**领域：** 饮用水 / 地方政府 / 环境监管 / 公共卫生  
**时间：** 2014–2022  
**机构：** City of Flint、Michigan 州机构、EPA、公共卫生机构  
**理论结果：** `supports`  
**证据等级：** `E4`

### 1. 事实基线

2014 年 Flint 改变市政供水来源后，腐蚀性更强的水在缺乏充分腐蚀控制的情况下进入供水系统，导致管道腐蚀并使铅等污染物进入饮用水。CDC 记录了供水切换及随后公共卫生应急过程。EPA OIG 2018 年报告认为，联邦、州和地方层面都存在实施与监督缺口，EPA 自身管理弱点也延迟了响应。

### 2. 关系结构

`水源选择 → 水处理 → 管网材料 → 水质检测 → 地方运营 → 州监管 → 联邦监督 → 居民健康`

饮水安全不是一个机构的产品，而是一串机构和技术节点共同制造的连续服务。

### 3. 脏现实作用力

- 成本与基础设施约束；
- 技术信息分散；
- 多层监管；
- 居民投诉与官方指标之间的冲突；
- 各层机构的权限边界；
- 问题一旦承认，组织会面临巨大的政治和法律成本。

### 4. 偏移机制

`局部决策 → 技术风险未被充分吸收 → 异常信号跨机构传递缓慢 → 每一层都只拥有部分权限和部分信息 → 责任难以迅速集中 → 暴露持续`

### 5. 竞争解释

不能把事件全部归结为“政府为了省钱”。水化学、基础设施老化、法规解释和组织能力同样是核心变量。成本动机即使存在，也只是结构的一部分。

### 6. 纠错机制

紧急命令权限澄清、饮水项目监督强化、腐蚀控制规则改进、风险评估和培训改进，都是把跨层责任重新闭合。

### 7. 对 Human 的修正

支持“跨机构责任扩散”模型，也说明 Human 在分析公共系统时应优先问：

> 谁拥有检测权？谁有解释权？谁有行动权？谁承担错误成本？这四者是否在同一节点？

---

# 第一卷综合结论

这 12 个案例没有证明“脏现实结构场论是真的”。

它们更谨慎地支持几个重复出现的结构模式：

### A. Proxy 可以获得现实权力

考试分数、销售数、财务指标、engagement、论文发表量，本来都是代理变量。

一旦代理变量与资源、晋升、奖金、组织资格绑定，它就不再只是“测量现实”，而会开始**塑造现实**。

### B. 信息最大的敌人不一定是缺失，而可能是拓扑

Challenger、9/11、Mayfield、Mid Staffordshire 都说明：

`有人知道 ≠ 组织知道`

`组织知道 ≠ 决策者知道`

`决策者知道 ≠ 信息拥有足够权重`

### C. 机构偏移经常不是恶意阴谋

很多失败可以在没有统一恶意意图的情况下产生：

`每个人局部合理 → 系统整体失效`

这比“坏人解释”更难处理，因为不存在一个单点反派可删除。

### D. 信任、预期和叙事只有接入行为才获得因果力

SVB 表明，信心通过提款进入资产负债表；平台极化通过点击与分享进入排序；医院声誉通过监管与管理决策进入资源配置。

因此 Human 以后讨论“叙事场”“信任场”，必须追问：

> 它通过哪个可观察行为接口进入现实？

如果没有这个接口，就只能算解释性隐喻，不能当因果变量。

### E. 纠错机制本身也是人类文明的重要机构能力

这些案例并不只证明机构会坏。

OIG、Rogers Commission、Francis Inquiry、FERC/NERC、CFPB、国会调查、开放科研改革等也证明：

`机构会偏移 → 人类又建立另一层机构去观察偏移`

所以完整模型不是：

`机构 → 腐败`

而是：

`机构 → 偏移可能 → 监测/申诉/审计/竞争/调查 → 纠正或再次偏移`

这才是人类社会真正的动态结构。

---

# 第二卷应重点寻找什么

第一卷偏重“失败”。第二卷必须故意增加三类材料：

1. **反例**：强指标但没有造成使命替代的机构；
2. **成功纠错**：机构在危机前主动识别并修正风险；
3. **集体智能**：群体/机构明显优于单个专家的案例。

否则 Casebook 会产生新的选择偏差：只看人类失败，就会错误地把 Human 训练成悲观主义机器。

下一卷的原则应是：

> **失败案例与成功案例至少 1:1。**
